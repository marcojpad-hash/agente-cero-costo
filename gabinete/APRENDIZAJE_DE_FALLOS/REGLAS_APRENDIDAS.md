# Reglas aprendidas

Registro transversal de controles preventivos derivados de incidentes con evidencia. Cada regla debe enlazar al expediente que la originó.

## Reglas vigentes

Todavía no hay reglas de incidente formalizadas. Las obligaciones generales están definidas en [el contrato](CONTRATO_INGENIERIA_INVERSA.md).

## Formato para nuevas reglas

### RL-AAAA-NNN — Título corto
- **Origen:** ID del incidente.
- **Patrón que evita:**
- **Regla verificable:**
- **Ámbito / agentes afectados:**
- **Comprobación previa:**
- **Test o control automatizado:**
- **Fecha de alta y última revisión:**
- **Estado:** ACTIVA / REVISAR / RETIRADA.

No incorporar como regla general una hipótesis no verificada. Las reglas retiradas se conservan con su motivo y fecha.
